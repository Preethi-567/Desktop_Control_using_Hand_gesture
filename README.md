# Desktop_Control_using_Hand_gesture
# Desktop Gesture Control

## Overview
Control your desktop using hand gestures detected via webcam.

## Features
- Cursor movement using hand tracking
- Gesture-based clicking
- Voice feedback
- Safety layer to prevent accidental triggers
- Performance monitoring

## Tech Stack
Python, OpenCV, MediaPipe, TensorFlow Lite

## Project Architecture
modules/
utils/
models/

## Installation
pip install -r requirements.txt

## Run
python main.py
